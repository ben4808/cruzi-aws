Analyze the distinct senses of the following word or phrase: [[PHRASE]]
Language of the item: [[SOURCE_LANGUAGE]]
Language of translations: [[TRANSLATION_LANGUAGE]]

EXISTING SENSES
[[REFERENCE SENSES]]

LANGUAGE
Write all output in the language of the item, with the exception of the Natural and Colloquial Translations.

TASKS
1. If the item is uninterpretable gibberish, reply ONLY with the word "Nonsense".

2. Generate senses from the item alone. Ignore Existing Senses until step 3. Cover every distinct attested reading.
  - The item is presented all caps. Also consider it lowercase and with natural capitalization. 
  - Different part of speech → different sense.
  - Different classification → different sense. Consider each of Word, Phrase, Proper Name, Acronym/Abbreviation, Prefix/Suffix, but only output a sense when that reading is actually used.
  - Each sense has its own display text: the usual way that reading is written. Do not expand an acronym into its full phrase as display text.
  - One meaning per sense. If you would write "A or B", split into two senses.

3. Then match. For each generated sense, look at Existing Senses.
  - Same meaning → in "Corresponding existing sense", paste that existing short description character-for-character. Leave your own short description as you wrote it; do not rewrite it to match.
  - No match → None

4. Frequency: exactly one tier per sense, and exactly one Primary in the whole output.
  - Primary: the single most dominant, immediate usage. If two are tied, pick the most historically rooted.
  - Common: standard and recognizable.
  - Uncommon: rare, archaic, or highly technical.

5. Base form: if the item is an inflected form of that sense, output its citation/base form. e.g. "Base form: tree"
  - Item is already in base form, or does not inflect (typical for names, acronyms, affixes): (None)

6. Translations and alternatives: 1–3 each. Empty → (None)
  - Natural: default equivalents in the Translation Language.
  - Colloquial: informal equivalents in the Translation Language.
  - Alternatives: other ways to say this same sense in the language of the item.

OUTPUT
Format below, nothing else. One blank line between senses.
Short description: as short as possible, only to tell this sense apart from the others.

([Part of Speech], [Classification], [Frequency]) [Display Text]
[Short Description] : [Definition]
Base form: [Base form, or (None)]
Natural: [Translation 1; Translation 2]
Colloquial: [Translation 1; Translation 2]
Alternatives: [Alternative 1; Alternative 2]
Corresponding existing sense: [Exact existing short description, or None]
