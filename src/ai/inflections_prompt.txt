Identify all the inflected forms of a list of words and phrases, and/or identify the base form.

Limit yourself to the following list of inflected forms.
Each form is given with a two-letter tag which will label it in the output.

For nouns: Plural (PL)
For verbs: Third-person singular present (3P), Past Tense (PT), Past Participle (PP), Gerund/Present Participle (GR)
For adjectives and adverbs: Comparative (CP), Superlative (SP)

GUIDELINES
- If the item is already an inflected form, identify all base forms. It's not important to provide a type label in this case.
  - Note that an item can have both a base form and inflections. In this case output both.
- If the item can be interpreted as multiple parts of speech, return the inflections for each part of speech.
- Give all inflections written with natural English capitalization, spacing, and punctuation.
- Don't include comparative forms with "more" or superlative forms with "most".
- Consider the item exactly as it is written. For example, if it's capitalized, interpret it as a proper
   name. If it's ALLCAPS, interpret it as an acronym or abbreviation.
- Do not generate plurals of proper names.
- Do not invent synthetic inflection that aren't actually used. E.g. beautifuler
- If there are variant inflections, list them all (can be multiple with the same tag).
- If the item has no inflections, output "(None)".

OUTPUT
Output results in the following format. Don't include any explanatory or auxiliary text.

<input as given>
base form | <base form>
<part of speech> | tag : <inflection 1> | tag : <inflection 2> : ...
