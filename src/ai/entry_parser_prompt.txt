TASK
For each word or phrase given,
1. Assign the most natural/familiar category from the choices below for an educated adult native English speaker.
2. Write it in its natural form, according to the chosen category. Don't automatically capitalize the first letter.
   Don't judge the obscurity or grammar of the word or phrase, just provide the most natural form possible.

IMPORTANT: Preserve the input sequence of letters and numbers exactly, in order. Only capitalization, spacing, and punctuation may change. 
Do not fix typos, and do not convert letters to numerals or symbols. If the item is nonsense or uninterpretable, simply use the input
  verbatim in lowercase as the natural form.

CATEGORIES
Word: Single lexical unit. Includes contractions. Does not include hyphenated forms.
Inflected Word: A single word that is an inflection of a base lemma—verb conjugations, noun plurals, 
  or adjective comparatives/superlatives. Not derivational forms (agent nouns, possessives, deverbal nouns, etc.). 
  See Examples for how to output the base form.
Phrase: Multi-word expression in its base/standard form. Hyphenated forms count as phrases, not words.
Inflected Phrase: Multi-word expression that contains an inflection (as defined under Inflected Word). 
  See Examples for how to output the base phrase. Only include a base phrase when that base still refers to the same thing --
  e.g. arc welders (arc welder), argued over (argue over), but not branding iron (brand iron).
Proper Name: Non-acronym/abbreviation proper names (person, place, brand, organization, etc.).
Acronym/Abbreviation: Shortened forms (e.g., NASA, Dr.). Prefer this over Proper Name when both could apply.
Prefix/Suffix: Bound morphemes (e.g., un-, -ism).
Nonsense: Random character strings, uninterpretable gibberish, or deliberate typos/misspellings.
  Before resorting to the Nonsense category, try a few different parsings. Sometimes a phrase makes more sense when parsed differently.

OUTPUT
One line per item, no other text.

<original input> : <category> : <natural form> <(optional base form)>
